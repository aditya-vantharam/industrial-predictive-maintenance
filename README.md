# industrial-predictive-maintenance
# 🏭 Machine Reliability Monitor

An industrial predictive maintenance application that uses
machine learning to estimate the risk of equipment failure.

## 🚀 Live Application

👉 [Open Machine Reliability Monitor](https://aditya-vantharam-industrial-predictive-maintenance-app-cbqzcz.streamlit.app/)

## Features

- Machine failure prediction
- Failure probability estimation
- Machine health assessment
- Operating parameter analysis
- Maintenance recommendations

## Technologies

- Python
- Streamlit
- Pandas
- XGBoost
- Joblib
- Machine Learning
